  TPC                  STM32 Trusted Package Creator v2.23.0
  Keys                 ST default keys from ROT_Provisioning/STiROT_OEMuROT/Keys (not for products)

Method
  The script copies OEMiROT_Boot, OEMiROT_Appli and ROT_Provisioning out of CubeH5 and symlinks
  Drivers, Middlewares and Utilities. CubeH5 itself is only read. In the copy it:
  - sets env.sh oemirot_appli_path_project to Applications/ROT/OEMiROT_Appli (full-secure app),
  - uncomments OEMUROT_ENABLE with AppliCfg (as STiROT_OEMuROT/provisioning.sh does),
  - sets MCUBOOT_APP_IMAGE_NUMBER 1 and FLASH_NS_PARTITION_SIZE 0x0 (full-secure layout, R-01),
  - sets the STiRoT code image version (OEMuRoT image) to 2.0.0 (decision D-04),
  - generates the obk files with the same TPC calls as provisioning.sh step 1,
  - compiles both projects with the sources, defines and includes of their STM32CubeIDE
    .project/.cproject (Debug), and runs ST's own postbuild.sh for each.
  ST's boot postbuild propagates the preprocessed layout into the app linker script, app headers,
  image XMLs, img_config.sh and ob_flash_programming.sh. Every change in the copy is in
  2026-10-05-m6-e61-cube-changes.diff.
