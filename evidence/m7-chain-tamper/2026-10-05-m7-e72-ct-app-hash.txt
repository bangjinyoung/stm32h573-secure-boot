## Reading

- STiRoT accepted OEMuRoT 2.0.0 (its banner), so the HDPL1 -> HDPL2 boundary passed as before.
- OEMuRoT checked the security counter (equal, ok) and rejected the primary slot before the
  signature TLV: the hash-stage path the H0 code reading predicted (image_validate.c:443-459).
- Prediction corrected: the end state is not Error_Handler. With no bootable image OEMuRoT calls
  boot_platform_noimage() (MCUBOOT_EXT_LOADER, OEMiROT_Boot/Inc/flash_layout.h:34), which jumps
  to the System Bootloader through RSS JumpHDPLvl3NS (boot_hal.c:113-145). ERROR_HANDLER_STOP_EXEC
  only affects Error_Handler paths, such as the OBK error seen with SW1=0.
- Test A (CT-BL-EXEC) is also expected to end in the System Bootloader, so the two are told apart
  by the OEMuRoT log, not by the end state: B has OEMuRoT lines, A has none.
